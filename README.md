# Shain Clip Relay site

Public homepage and privacy policy for the private Shain Clip Relay OAuth application.

## Publish with GitHub Pages

1. Create a public GitHub repository named `shain-clip-relay-site`.
2. Push this directory to its `main` branch.
3. In **Settings → Pages**, choose **Deploy from a branch**, `main`, and `/ (root)`.
4. Use the resulting URLs in Google Auth Platform:
   - Homepage: `https://YOUR_GITHUB_USERNAME.github.io/shain-clip-relay-site/`
   - Privacy policy: `https://YOUR_GITHUB_USERNAME.github.io/shain-clip-relay-site/privacy.html`
   - Authorized domain: `YOUR_GITHUB_USERNAME.github.io`

The site is static and uses no cookies, analytics, JavaScript, external fonts, or secret configuration.
